Interface guide

ScanReads /ledger/status from the listed ports and updates the counters/table.
Demo auto-scanDuring scripts/demo.py, auto-detects the helper server, updates host/ports from the running demo, and scans periodically.
Post tx to targetsSends one /tx request to each target port using the transaction prefix.
Read ledgersFetches /ledger from target ports and writes the full entries to the log.
Block/Unblock peerCalls /debug/faults on the fault source so it ignores or restores one outbound peer.
Forward off/onToggles direct transaction forwarding for Prax1-style gossip experiments.
Divergence actionsSelects base+0..2 and posts one tx to each direct-mode node.
Convergence actionsSelects base+100..104 and posts txs to the first three consensus nodes.
Bad actor actionsSelects base+200..202, sends an invalid /inv, then posts one valid tx.
Check no-quorumScans base+300 and checks whether a pending tx stayed uncommitted.
Check leader-failureScans base+150..154 and logs online nodes plus ledger hash count.
Scale 30 portsSelects base+500..529 for the 30-node demo or load harness.
Partition actionsSelects the two partition groups and posts one tx into each side.
Post load burstSends 12 txs round-robin across the current target ports.
BuildCreates the terminal command for the selected Python harness preset.
